# Experimental Simulations & Flow Visualizations

Add experimental flow visualization datasets here.
To add an experiment:
1. Create a subfolder, e.g. `microfluidic-droplets/`
2. Create `sim.json` inside it specifying:
   - `name`: Name of experiment
   - `method_tag`: "Experiment"
   - `subtag`: Sub-topic (e.g. "Microchannel flow")
   - `description`: Summary of the observation/setup
   - `media_type`: "video" or "image"
   - `media`: video/image paths
3. Push to GitHub, and it will automatically appear under the "Experiment" filter on your website!
